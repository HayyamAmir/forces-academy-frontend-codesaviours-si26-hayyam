
# 🎓 Forces Academy Frontend Website

A modern, responsive, and user-friendly frontend website developed for **Forces Academy** as part of the **Code Saviours Summer Internship SI-26 (2026)**.

This project was built using HTML5, CSS3, Bootstrap 5, and JavaScript. It provides an attractive and responsive interface for students to explore academy information, courses, admissions, results, gallery, and contact details.

# About the Project

Forces Academy Faisalabad is a responsive educational website designed to provide an online presence for the academy and make important academic information easily accessible to students and visitors.

The project was developed as part of the Code Saviours Summer Internship 2026 (SI-26) under the Frontend Development Track.

The main focus of this project was to build a professional frontend using modern web development technologies while maintaining:
- Clean and consistent UI
- Responsive design
- Easy navigation
- Mobile-friendly layouts
- Reusable styling
- Professional educational branding
- User-friendly content presentation

#  How to Run

To run the project locally:

1. Clone the repository
git clone YOUR_GITHUB_REPOSITORY_URL
2. Open the project folder
cd forces-academy-frontend
3. Run the website

Open index.html in your browser.

# Deployment

The website is deployed using GitHub Pages.

Deployment steps:

- Upload the project to GitHub.
- Push the project to the main branch.
- Open the repository settings.
- Go to Pages.
- Select the main branch.
- Select the root folder.
- Save the settings.
- GitHub Pages generates the live website URL.
